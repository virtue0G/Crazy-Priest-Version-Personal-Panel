# 个人成长系统

把日常记录变成两个东西：一张**修行面板**，和一张**知识星图**。

面板回答「我现在该干什么」；星图回答「我知道什么、还缺什么」。两者共用一套世界观设定，但**代码和数据是分开的**——这个仓库只装代码。

---

## 快速开始

```bash
cd system
python run.py init      # 建库 → 灌入示例数据 → 生成 panel.html
```

打开 `panel.html` 就能看到面板。

想边用边记、边确认证据，起个本地服务：

```bash
python run.py web       # http://127.0.0.1:8765
```

只依赖 Python 标准库，不需要装任何东西。

---

## 命令

| 命令 | 作用 |
|---|---|
| `init` | 首次建库 + 渲染 |
| `render` | 只重新渲染面板 |
| `rebuild` | 重灌数据 → 重新渲染 → 跑完整性自检（**不抹掉你已确认的证据**） |
| `check` | 完整性自检：孤儿证据、道痕守恒、HTML 标签配对 |
| `status` | 各道道痕与各蛊状态 |
| `confirm` | 确认待定证据，之后才计道痕 |
| `web` | 起本地服务（可随手记、可确认） |
| `selftest` | 改数据 → 断言面板跟着变 → 还原 |

星图单独生成：

```bash
cd kb
python build_starmap.py   # → 星图.html
```

## 数据放在哪

**这个仓库里没有你的真实数据，也不该有。**

| 位置 | 内容 | 入不入库 |
|---|---|---|
| `data/` | 你的真实记录与基线数据 | ❌ 已被 `.gitignore` 挡住 |
| `demo/` | 脱敏示例数据 | ✅ 入库 |

`system/baseline.py` 是唯一的读取口：**有 `data/baseline.json` 就用真实的，没有就回落到 `demo/baseline.json`。** 跑起来时输出里会写明用的是哪一份。

所以 clone 下来直接 `init` 就能看到一个有内容的示例面板；把你自己的记录放进 `data/baseline.json`，它就变成你的。

### 基线数据的格式

`demo/baseline.json` 就是模板，照着写即可：

```jsonc
{
  "evidence": [ ["2026-01-08", "做了什么", "产出", [["律道", 0.5]]] ],
  "new":      [ ["2026-05-25", "待确认的记录", "产出", [["炼道", 0.3]]] ],
  "wishes":   [ ["2026-05-27", "想做但没做", "为什么算愿望"] ],
  "moves":    [ ["杀招名", "状态", "需要的蛊", "人的判断", 1] ],
  "profile":  { "cultivation": "一转", "capacity": "稳定" },
  "aperture": [ ["2026-05-28", 70, "平稳", "状态正常"] ]
}
```

- `evidence` / `new` 每条 = `(日期, 文本, 来源类型, [(道, 权重)…])`，日期可为 `null`
- 来源类型取 `产出 / 协作 / 学习 / 踩坑 / 愿望`；权重单位是道痕
- `moves` 的 note 写「人的判断」——凡是能被算出来的（哪只蛊最饿、哪条道最浅）一律不写死，交给 `render.py` 现算

**代码里只有机制，没有内容：**

| 放哪 | 是什么 |
|---|---|
| `system/seed.py` | **结构设定**：八道、蛊、晋升阶梯、杀招的材料构成 |
| `baseline.json` | **个人内容**：证据、杀招的判断、自评、读数 |

分界线是「换个人还成立吗」——八道的名字换个人也这么叫，但一句针对某个具体的人的判断，只对那一个人成立。
后者一律进 JSON，代码里不留。

## 几条设计原则

这些不写在注释里容易忘，所以放这儿：

1. **能被算出来的，就别写死。** 哪只蛊最饿、哪条道最浅、今日炼什么——全部现算。写死的文案一定会过期。
2. **验证靠「改数据看输出跟不跟」，不靠人眼看一遍。** `run.py selftest` 就是干这个的。
3. **境界不可自评，由达成事件证明。** 门槛必须是「下一件够得着的事」，不是终极理想。
4. **缺口要显式显示，不能隐藏。** 记下的缺口、待补空洞、还没有对应知识域的道——都是信息，藏起来才是错。
